# Prismedia social launch kit

## Ready-to-publish artwork

All paths are relative to `docs/launch/product-hunt/assets/`.

| File | Size | Best use |
| --- | ---: | --- |
| `social-card-product-hunt.png` | 1200×630 | Link previews, GitHub Discussions, forum announcements, and landscape posts |
| `social-square-product-hunt.png` | 1080×1080 | Square social feeds and the one-light-in, every-medium-out brand story |
| `social-story-product-hunt.png` | 1080×1920 | Stories and vertical posts that need real web, Apple TV, and reader proof |

The source is `gallery.html`; regenerate and validate every export with:

```sh
node docs/launch/product-hunt/render-gallery.mjs
```

The renderer checks exact output geometry, marked-copy overflow, and a 5 MB upload
ceiling. The current three exports are each below 1 MB.

## Prism story post

**Artwork:** `social-square-product-hunt.png`

One light enters. Every medium comes out.

That is the idea behind Prismedia: movies, series, music, audiobooks, books, comics,
images, and galleries share a lifecycle, but today we make them pass through a stack
of disconnected products.

Prismedia gives the collection one private home—from “I want it” through watching,
listening, reading, and browsing.

<https://pauljoda.github.io/Prismedia/>

## Native-experience post

Self-hosting should not mean settling for generic playback or reading.

Prismedia pairs a complete web workspace with native iPhone, iPad, and Apple TV

progress that stays attached to the same library item.

## Publishing check

Before each post:

1. Confirm the August 23 launch remains scheduled and public by link.
2. Open the destination URL in a signed-out window.
3. Confirm TestFlight still accepts the limited testing group.
4. Use the matching alt text and preserve the artwork’s full aspect ratio.
5. Ask for use and candid feedback, never votes.
6. Review the visible media artwork for promotional-use rights.
