# Start Here

Prismedia brings movies, series, music, books, audiobooks, comics, images, and galleries into one private library. Run the server on your own computer or NAS, then use a browser or the native app to reach it.

Each title keeps its identity, metadata, files, and your progress together. Prismedia calls that library item an **Entity**. You do not need to understand the internal model to get started.

## Set up your first library

Start with a small folder of media so you can check the result before adding the rest of your collection.

1. **[Check what you need](./getting-started/before-you-install.md).** Understand the server, clients, and optional services.
2. **[Install the server](./getting-started/install.md).** Start the Docker container and create your administrator account.
3. **[Choose your folders](./getting-started/organize-folders.md).** Map your storage into the container and choose a watched root for each medium.
4. **[Scan and open an item](./getting-started/first-library.md).** Check that files appear in the right library, then play or read one.
5. **[Add artwork and metadata](./getting-started/identify-walkthrough.md).** Review a provider match and apply the information you want.

You can catalog and play existing files without setting up requests, indexers, or download clients.
