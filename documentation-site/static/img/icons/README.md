# Website icons

These use the same colored prism artwork as the Prismedia app. Keep the mark
unchanged when updating icons.

- `favicon.ico` contains 16, 32, 48, and 256 pixel PNG entries.
- `favicon-96.png` gives browsers a larger square favicon.
- `apple-touch-icon.png` is the 180 pixel home-screen icon.
- `icon-192.png` and `icon-512.png` are the regular manifest icons.
- `icon-maskable-512.png` has an opaque background and keeps the entire prism
  within the central safe circle (40% of the image width in radius).

The original app icon files live in `apps/web-svelte/static`. Website links and
the manifest are scoped to the public site's deployment path.
